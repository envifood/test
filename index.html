Важно:

  • Текст в ссылках закодирован: пробел = %20, спецсимволы тоже нужно кодировать.
  • В WhatsApp номер должен быть в международном формате без плюса и скобок (для РФ это 7XXXXXXXXXX).
  • Для Telegram укажите свой username без символа @.
  • Для VK замените vk.ru/im?sel=-XXXXXXXX на свой номер диалога.
  • MAX: у него нет стандартного шаблона ссылки. Используйте ту, которую скопируете из приложения («Поделиться» в QR-коде профиля). Её можно вставить как обычную ссылку без параметров.
